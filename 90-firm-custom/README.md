# 90-firm-custom

Empty scaffold for Neave Family Law Group, P.A.'s own skill derivatives.

Shipped LAL skills are never edited directly. When this firm needs a shipped
skill changed, run `lal-customize` (in Core Foundation) — it creates a
firm-prefixed derivative here (e.g. `neave-lal-drafting-core`) instead of
modifying the original, so future LAL updates never overwrite the firm's
changes.

This folder is intentionally empty until the firm's first customization.
