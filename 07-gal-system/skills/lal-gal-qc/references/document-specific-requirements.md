## Section 1 — GAL Contract

**Minimum required content:**
- [ ] Parties identified by name
- [ ] Child(ren) identified by name and DOB
- [ ] Case number
- [ ] Scope of GAL appointment referenced
- [ ] Fee structure (hourly rate / retainer / flat fee)
- [ ] Payment terms (who pays / split)
- [ ] Billing and invoice process
- [ ] Confidentiality acknowledgment
- [ ] Cooperation requirement
- [ ] Record release authorization
- [ ] Signature lines for both parties (and counsel if represented)
- [ ] GAL signature line

**Common issues:**
- [ ] Confirm fee split is consistent with court order
- [ ] Confirm scope matches appointment order
- [ ] Confirm both parties sign before investigation begins

## Section 2 — Acceptance of Appointment

**Minimum required content:**
- [ ] Court caption
- [ ] Reference to Order of Appointment (date)
- [ ] GAL name and credentials
- [ ] Acceptance statement
- [ ] Acknowledgment of scope
- [ ] Certificate of Service to all counsel
- [ ] Signature block

---

## Section 3 — Oath and Acceptance

**Minimum required content:**
- [ ] Court caption
- [ ] Reference to Order of Appointment
- [ ] Oath language (per Florida requirements)
- [ ] GAL name and credentials
- [ ] Notarization block (if required by local practice)
- [ ] Certificate of Service

---

## Section 4 — Initial Letter to Parties

**Minimum required content:**
- [ ] GAL name and contact information
- [ ] Reference to appointment
- [ ] Explanation of GAL's role (neutral — best interests of child)
- [ ] Explanation of what to expect (interviews, home visits, record requests)
- [ ] Confidentiality notice
- [ ] Instructions for scheduling initial interview
- [ ] Instructions for providing collateral contact information
- [ ] Request for initial records (school, medical, other as applicable)
- [ ] No-contact with child about report content notice
- [ ] Contact information for GAL

**Sent to:** Both parties (via counsel if represented; directly if pro se)

---

## Section 5 — Collateral Contact Letter

**Minimum required content:**
- [ ] GAL name and contact information
- [ ] Reference to appointment and case
- [ ] Identification of the collateral and their role
- [ ] Purpose of contact
- [ ] Confidentiality notice
- [ ] Request for interview / records (specify)
- [ ] Authorization language (if requesting records)
- [ ] Contact information and response deadline

**Attach:** Signed records authorization from the relevant party, if required

---

## Section 6 — Motion to Compel Fees

**Minimum required content:**
- [ ] Court caption
- [ ] Reference to original fee order / contract
- [ ] Amount owed by each party (itemized)
- [ ] Dates of invoices and non-payment
- [ ] Prior demand (if made)
- [ ] Relief requested (amount, interest, fees on fees if applicable)
- [ ] Certificate of Service

---

## Section 7 — Motion to Adopt Recommendations

**Minimum required content:**
- [ ] Court caption
- [ ] Reference to GAL report (date, exhibit designation)
- [ ] Summary of recommendations sought to be adopted
- [ ] Legal basis for adoption
- [ ] Proposed order attached
- [ ] Certificate of Service

---

## Section 8 — Motion for Psychological Evaluation

**Minimum required content:**
- [ ] Court caption
- [ ] Basis for the request (specific observations / concerns from investigation)
- [ ] Who is to be evaluated (party / child / both)
- [ ] Proposed scope
- [ ] Proposed evaluator selection process
- [ ] Proposed cost allocation
- [ ] Proposed order attached (see evaluation-order-key-clauses.md)
- [ ] Certificate of Service

---

## Section 9 — Motion for Psycho-Educational Evaluation

**Minimum required content:**
- [ ] Court caption
- [ ] Child identified (initials, DOB, grade level)
- [ ] Basis for request (specific academic or developmental concerns)
- [ ] Proposed evaluator and credential requirements
- [ ] Proposed scope (testing battery)
- [ ] Cost allocation
- [ ] School notification provision
- [ ] Proposed order attached
- [ ] Certificate of Service

---

## Section 10 — Motion for Substance Abuse Evaluation

**Minimum required content:**
- [ ] Court caption
- [ ] Party to be evaluated
- [ ] Basis for request (specific documented concerns — not bare allegations)
- [ ] Proposed evaluator credential requirements
- [ ] Proposed testing protocol
- [ ] Proposed cost allocation
- [ ] Random testing authorization (if sought)
- [ ] Proposed order attached (see evaluation-order-key-clauses.md)
- [ ] Certificate of Service
