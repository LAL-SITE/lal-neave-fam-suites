# Credibility Signals — Assessment Framework
## PLACEHOLDER REFERENCE FILE
### For evaluating reliability of sources and accounts in GAL investigation

---

> ⚠️ This is a placeholder reference file. No case-specific information has been entered.
> Apply this framework when assessing any source's reliability in the current matter.

---

## Core Principle

Credibility assessment is not about deciding who is a good or bad person.
It is about evaluating whether a specific account is reliable.

The GAL does not make credibility rulings — that is the court's function.
The GAL identifies credibility signals and documents them accurately.

---

## Signal Category 1 — Internal Consistency

Does this source's account remain consistent across contacts?

| Signal | Observation to Document |
|--------|------------------------|
| Consistent across interviews | Note if account remains the same |
| Inconsistency within one interview | Quote the specific inconsistency |
| Inconsistency across interviews | Note what changed and when |
| Inconsistency with prior statements (records) | Identify the record and the discrepancy |

**Documentation template:**
> "[Source] stated [X] during the [date] interview. However, in [record/prior contact dated],
> [Source] stated [Y]. The GAL notes this inconsistency without resolving it."

---

## Signal Category 2 — External Corroboration

Is the account supported by independent sources?

| Signal | Observation to Document |
|--------|------------------------|
| Corroborated by records | Identify the record |
| Corroborated by independent collateral | Identify the collateral |
| Contradicted by records | Identify the record |
| Contradicted by collateral | Identify the collateral |
| No corroboration available | Note what corroboration would be expected |

---

## Signal Category 3 — Basis of Knowledge

How does this source know what they claim to know?

| Signal | Observation to Document |
|--------|------------------------|
| Direct observation | Note frequency and context |
| Secondhand report | Note who told them |
| Inference only | Note the basis for the inference |
| Unclear basis | Flag for follow-up |

---

## Signal Category 4 — Apparent Bias or Motivation

Does this source have a reason to shade their account?

| Signal | Observation to Document |
|--------|------------------------|
| Family relationship with a party | Note relationship; note potential alignment |
| Financial interest | Note if applicable |
| Personal conflict with a party | Note if disclosed or apparent |
| Professional neutrality | Note credential and role |
| Court-ordered neutrality (evaluator) | Note appointment and scope |

> ⚠️ Note apparent bias — do not state it as a fact unless documented.

---

## Signal Category 5 — Child-Specific Signals

For child statements, additional signals apply:

| Signal | Observation to Document |
|--------|------------------------|
| Spontaneous disclosure | Note that it was unprompted |
| Responsive to questioning | Note the question that prompted it |
| Adult language or phrasing | Quote the specific language |
| Child-appropriate language | Note |
| Emotional congruence | Does the child's affect match the content? |
| Apparent comfort / discomfort | Note the child's demeanor |
| Prior coaching alleged | Note any indicators; do not conclude |

---

## Signal Category 6 — Behavioral Specificity

Accounts with specific behavioral detail are generally more reliable than vague accounts.

| ❌ Vague | ✅ Specific |
|---------|-----------|
| "He's always angry" | "On [date], Father yelled [specific words] in front of the child, according to Mother." |
| "She doesn't care about the kids" | "Mother did not attend [specific event] on [date], per school records." |
| "He drinks all the time" | "Father acknowledged drinking [amount] on [frequency], per his own statement." |

---

## Using This Framework

1. After each source contact, run through the five signal categories
2. Document positive and negative signals — both matter
3. Do not reach a credibility conclusion — document the signals and let the report present them
4. Flag significant credibility conflicts for the findings section
