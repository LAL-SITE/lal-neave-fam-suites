## INTERIM — FIRST REPORT CHECKLIST

### Section I — Background Information
- [ ] Appointment paragraph included (order date, child name(s), DOB(s))
- [ ] Acceptance of Appointment filing date included
- [ ] All pending motions listed with file dates
- [ ] Hearing date stated (or "no pending hearings" if none)
- [ ] 10-day waiver status addressed
- [ ] Confidentiality footnote present

### Section II — GAL's Investigation
- [ ] Statement that this is an interim / partial investigation
- [ ] Documents reviewed listed
- [ ] Home visit(s) noted with date(s)
- [ ] Collateral contacts listed
- [ ] Phone tag / non-responsive contacts listed
- [ ] Closing "comfortable making temporary recommendations" statement included

### Section IV — Temporary Recommendations
- [ ] Labeled as TEMPORARY
- [ ] Each recommendation is specific and actionable
- [ ] Each recommendation is tied to a stated observation or finding
- [ ] Closing catch-all language included
- [ ] Signed and dated

### Final Check
- [ ] Court caption correct (case number, division, county, parties)
- [ ] No real child name in body — initials only per local practice
- [ ] Confidentiality footer present
- [ ] Certificate of Service complete with all counsel emails

---

## INTERIM — SUBSEQUENT REPORT CHECKLIST

*(All items from First Report apply, plus:)*

### Section I — Additional Requirements
- [ ] Prior report(s) referenced by date and designated as Exhibit(s)
- [ ] Statement that new report covers investigation since last report
- [ ] Prior reports attached as exhibits

### Recommendations
- [ ] Labeled as UPDATED RECOMMENDATIONS
- [ ] Changed recommendations identified with reason for change
- [ ] Unchanged recommendations carried forward

---

## FINAL REPORT CHECKLIST

### Pre-Flight — Investigation Completeness
- [ ] Both parents interviewed
- [ ] Both home visits completed
- [ ] Child(ren) interviewed (or developmental limitation documented)
- [ ] All HIGH-priority gaps resolved or explicitly acknowledged
- [ ] Key records received and reviewed
- [ ] All identified collaterals contacted or documented non-responsive

### Section I — Background Information
- [ ] All items from interim checklist
- [ ] Issues the GAL was asked to address listed explicitly
- [ ] All prior reports referenced with dates and exhibit designations

### Section II — GAL's Investigation
- [ ] Complete investigation log (all sources, all records, all contacts)
- [ ] No "ongoing" language — investigation stated as complete (or limitation noted)

### Section III — Observations and Insights
- [ ] Mother section complete (numbered paragraphs)
- [ ] Father section complete (numbered paragraphs)
- [ ] Child(ren) section complete (each child separately if multiple)
- [ ] Each collateral addressed (professionals first, then lay)
- [ ] All contrary accounts addressed — not omitted

### Section IV — Findings and Recommendations
- [ ] Organized by applicable §61.13(3) factors
- [ ] Each factor: findings stated → recommendation stated
- [ ] Findings and recommendations strictly separated (no mixing)
- [ ] Every recommendation is specific, traceable, enforceable, and explained
- [ ] Non-applicable factors noted with brief reason
- [ ] Summary recommendations included (complex cases)

### Final Check
- [ ] All items from interim final check
- [ ] No recommendation lacks a supporting finding
- [ ] No finding lacks a source attribution
- [ ] No allegation treated as a fact
