## Primary Status Labels

Every event in the chronology receives one primary status label:

| Label | Definition | When to Use |
|-------|-----------|-------------|
| **DOCUMENTED** | Confirmed by a record or filing | Court order, school record, medical record, DCF record, police report |
| **REPORTED** | Stated by a source; not independently confirmed | Party statement, collateral account, child disclosure |
| **ALLEGED** | Claimed by one party; disputed or unverified | One party's claim that the other disputes |
| **CORROBORATED** | Reported by multiple independent sources | Two or more independent sources confirm the same event |
| **DISPUTED** | Sources give conflicting accounts of this event | Parties or sources contradict each other |
| **INFERRED** | Logically follows from documented facts | The event itself is not directly documented |
| **UNKNOWN** | Cannot be confirmed or denied from available sources | Records not yet received; sources not yet contacted |

## Secondary Labels (Apply in Addition to Primary)

| Label | Definition |
|-------|-----------|
| **HIGH SIGNIFICANCE** | Directly relevant to a key issue in the case |
| **CHILD PRESENT** | Child was present for this event |
| **CHILD INVOLVED** | Event directly involved or affected the child |
| **COURT-ORDERED** | Required or established by court order |
| **COMPLIANCE — YES** | Party complied with an order or agreement |
| **COMPLIANCE — NO** | Party failed to comply with an order or agreement |
| **ESCALATION** | Represents a worsening of a prior pattern |
| **PROTECTIVE** | Represents a positive or stabilizing event |
| **REQUIRES FOLLOW-UP** | Additional investigation needed |

## Chronology Entry Format

Each entry in the case chronology uses this format:

```
DATE: [MM/DD/YYYY] or [Approximate — Month/Year] or [Unknown]

EVENT: [Brief neutral description of what occurred]

SOURCE: [Document / Record / Party name / Collateral name]

STATUS: [PRIMARY LABEL] + [SECONDARY LABEL(S) if applicable]

NOTES: [Relevance to case issues; questions raised; follow-up needed]
```

## Dating Conventions

| Situation | Convention |
|-----------|-----------|
| Exact date known | MM/DD/YYYY |
| Month and year known | Month YYYY |
| Year only known | YYYY |
| Approximate | "Approx. [time period]" |
| Before/after reference | "Before [event]" / "After [event]" |
| Unknown | "Date unknown" |

## Source Attribution in Chronology

| Source Type | Attribution Format |
|-------------|-------------------|
| Court filing | "Per [document title] filed [date]" |
| Record | "Per [record type] from [provider] dated [date]" |
| Party statement | "Per [Mother/Father], interview dated [date]" |
| Collateral | "Per [Name, role], contact dated [date]" |
| Child | "Per child, [describe context — home visit / interview]" |
| GAL observation | "GAL observation — [date and setting]" |

## Chronology Sections

Organize the full chronology into the following sections:

1. **Pre-Litigation History** — Events before any court filing
2. **Litigation Timeline** — All court filings, orders, and hearings in order
3. **Relevant Incidents** — Events relevant to the case issues (parenting, conflict, child concerns)
4. **Investigation Timeline** — GAL contacts, visits, and record receipts
