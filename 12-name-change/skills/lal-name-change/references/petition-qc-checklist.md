# Petition QC Checklist (run before filing)

Run a drafted petition against BOTH the matching Florida Supreme Court 12.982 form
and the client's intake form. This is a paralegal QC pass; the attorney still does the
final review and sign-off. Nothing files without attorney approval.

## A. Right form for the situation
- [ ] Case type matches the template: Adult #01 / Minor #02 / Family #03
      (restoration → #01 with restoration language).
- [ ] Matching Final Judgment prepared: #13 / #14 / #15.
- [ ] Minor or family → **UCCJEA Affidavit (#09)** included.
- [ ] Minor with a non-co-petitioner parent → **Consent (#04)** attached, **or** a
      service posture is set and flagged to the attorney.
- [ ] Cover Sheet 12.928 accounted for (usually portal-generated — confirm per county).
- [ ] Companion filings prepared as needed: NOA (#05 or #06), Email Designation
      (#07), Notice of Related Cases (#08, after a case search).

## B. Caption & formatting (firm standard)
- [ ] Correct circuit and county (venue = petitioner's county of residence).
- [ ] Case number / division as `[PLACEHOLDER]` if not yet assigned — never invented.
- [ ] Party name and "IN RE:" line are **regular weight, normal case** (not bold/ALL-CAPS).
- [ ] Numbered/lettered paragraphs **hang-indent**.
- [ ] Times New Roman 12-pt, proper spacing (apply the `docx` skill formatting rules).

## C. § 68.07 content complete (cross-check intake, no blanks left unbracketed)
- [ ] Present name + proposed name.
- [ ] Residence (county + full address).
- [ ] DOB + place of birth; birth cert referenced as Exhibit A.
- [ ] Father's name; mother's name + maiden name.
- [ ] Complete residence history since birth (addresses + date ranges).
- [ ] Family (marital status / spouse).
- [ ] Former names / prior court-ordered changes (when/where/why if any).
- [ ] Occupation; current employer; 5-year employment history.
- [ ] Business ownership; profession/license; education.
- [ ] Criminal-history statement.
- [ ] **§ 68.07(3)(i) sexual-predator/offender disclosure** present (or, in the Sixth
      Circuit, filed as standalone #23).
- [ ] Bankruptcy + creditor-judgment statements.
- [ ] Fingerprints / records-check paragraph present (omit only for restoration).
- [ ] No-ulterior-purpose + civil-rights statements.
- [ ] Prayer for relief names the exact proposed name.

## D. Signature & verification
- [ ] Sworn-statement line present.
- [ ] Petitioner signature line + notary block.
- [ ] Firm signature block correct (Angela R. Neave FBN {{BAR_NO}} / Angela R. Neave Bar No. {{BAR_NO}}; firm address;
      aneave@neavefamilylaw.com).
- [ ] Certificate of Service included where the other parent is served.

## E. Consistency & integrity
- [ ] Every data point matches the intake (names spelled identically throughout).
- [ ] No fabricated case numbers, ORI numbers, judges, or hearing details.
- [ ] Any remaining unknowns are bracketed `[PLACEHOLDERS]`.
- [ ] No case law added (per `lal-caselaw-protocol`) unless from firm project files.

## F. Scope
- [ ] Anything beyond flat-fee scope (contested service, custody overlap, litigation)
      is flagged to the attorney **before** filing.
