# Divorce Petition Drafting Reference

## Required Initial Packet (New Dissolution Case)
- Petition for Dissolution of Marriage
- Civil Cover Sheet
- UCCJA / UCCJEA (when minor children are involved — can be inside petition or separate)
- Summons (issued by clerk after filing)

## Required Allegations in Every Divorce Petition
1. **Jurisdiction** — One party has been a Florida resident for at least 6 months immediately preceding filing
2. **Venue** — The county where one party currently resides
3. **Date and place of marriage**
4. **Ground for dissolution** — The marriage is irretrievably broken (Florida is a no-fault state — use this standard language)
5. **Minor children** — Names and DOBs of all minor children of the marriage (including biological children of both parties and adopted children)
6. **Parenting allegations** — If children exist, must address parental responsibility and timesharing (petition must plead what the client is requesting)
7. **Property and debts** — Must address equitable distribution of marital assets and liabilities; include partition count if real property exists and client is on title
8. **Support** — Address child support if applicable; address alimony if applicable
9. **Attorney's fees** — If requesting fees, plead it
10. **Name restoration** — Must be pled here if client wants it; cannot be added later without amendment

## PEACE Checklist — Every Dissolution Petition
Before finalizing, confirm each PEACE element is addressed or explicitly waived:
- [ ] **P**arenting — timesharing, parental responsibility, parenting plan
- [ ] **E**quitable Distribution — marital assets, marital debts, non-marital property
- [ ] **A**limony — bridge-the-gap, rehabilitative, durational, permanent (address even to deny)
- [ ] **C**hild Support — include if minor children exist
- [ ] **E**verything else — attorney's fees, name change, deeds/title transfers, account designations

## Common Optional / Situational Counts
- **Relocation** — if client seeks to move child 50+ miles; requires detailed pleading
- **Exclusive use and possession** — if seeking to exclude spouse from marital home (flag for attorney; not routine)
- **Temporary relief** — address in separate motion; not in the petition itself

## Real Estate Handling
- If marital real property exists → include partition count (even if client hopes to keep the home — buyout negotiated later)
- **Verify ownership before pleading partition** using the county Property Appraiser website
- Save/print the Property Appraiser page to the file
- Use Zillow for a working estimate of value (note date); Property Appraiser values are tax-based, not market-accurate

## UCCJA / UCCJEA Allegations (When Children Are Involved)
- Must plead where the children have lived for the past 6 months (or since birth for newborns)
- If another state previously issued a custody determination, flag for attorney — interstate jurisdiction issues require attorney decision
- Paralegals do not decide interstate jurisdiction disputes

## Military Status
- If either party is active duty military → flag immediately for attorney
- Active duty status affects service, abatement, and procedural rights
- "Veteran" is not the same as "active duty"

## Signature Block
The petition is **signed by the client (Petitioner)**, not just by counsel. Must be
verified (sworn under penalty of perjury) or signed under § 92.525 certification.
Attorney's signature block appears separately below client signature.

## Financial Affidavit Note
- Short-form FA if income under $50,000/year; long-form if over
- Must be filed; it is a frequent bottleneck
- File what the client gives you on time — amend later as discovery develops
- Do a quick sanity check (missing sections, obvious errors) before filing
